## Usage

```bash
nxg -i [nix package]   # Install a package
nxg -s [search term]   # Search for packages
nxg -u [nix package]   # Uninstall a package
nxg -fu                # Update flake inputs
nxg -c                 # Clean up
nxg -list              # List configured packages
nxg -settings          # Configure Nixgram settings
```
